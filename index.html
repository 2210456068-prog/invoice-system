① 批量粘贴 / Excel 导入

把发票按下面格式一行一条粘贴进来（逗号或制表符分隔都可），或从 Excel 里复制一片区域直接粘贴。也可上传 .csv 文件。下方「③ 电子税务局 Excel 导入」可直接识别税局批量导出的表格。

③ 电子税务局 Excel 导入

把在电子税务局「全量发票查询」里批量导出的 Excel（.xlsx/.xls）拖进来或选文件，系统会自动识别列、判断销项/进项、并填好金额税额，预览确认后一键入账。不会上传到任何云端，全程本地解析。

说明：自动判断会拿表格里的「销售方名称 / 购买方名称」和你系统里的公司名做匹配——本公司是销售方就归为销项，是购买方就归为进项。若公司名对不上（如用的是简称），选「全部作为销项/进项」并指定公司即可。

② 拍照 / 扫码识别（发票二维码）

上传一张发票图片或截图（含右上角二维码即可），系统本地解码并自动填字段。不会上传到任何云端。

说明：大多数增值税专票 / 电子发票都带二维码，解码即可拿到发票号码、日期、金额等。若发票没有二维码或识别不准，请用上方「批量粘贴」或手动录入，并务必核对金额。

数据备份与导出

数据保存在本机浏览器。建议定期导出备份，换电脑或清缓存前务必先导出。

导出的 .csv 可直接用 Excel / WPS 打开。若后续想让我把数据同步到飞书表格或腾讯文档，随时说一声即可。

公司 / 账套

管理公司名称（重命名 / 新增 / 删除）。改名后，已录入的发票与台账会自动跟随改名。

纳税人类型

影响「应交增值税」计算。小规模纳税人进项税不抵扣（按销项不含税 × 征收率交税）；一般纳税人进项税可抵扣（销项税 − 进项税）。

使用说明

基础操作（打开 / 录入 / 税率 / 筛选）
  1. 打开方式：浏览器打开即可，数据保存在本机浏览器。
  2. 录入发票：点「录入发票」，先选销项（你开给客户的）或进项（供应商开给你的），填号码、日期、对方、税率、不含税金额，系统自动算税额和价税合计。
  3. 税率：常用 13% / 9% / 6% / 3% / 1%，没有就选「自定义」。小规模纳税人常用 1% 或 3%。
  4. 查看与筛选：「发票列表」可按类型、状态、日期、关键字筛选；点「编辑」可改，点「删除」可删。
核心功能（概览 / 台账 / 收付款 / 飞书）
  1. 概览：自动统计销项、进项、估算应交增值税和月度走势，顶部提醒条会列出逾期未收、待付款。
  2. 记账台账：记录每日银行/现金/微信/支付宝收支，自动算余额；在「发票列表」点「记收付款」可把发票一键转为收付款记录。
  3. 收付款跟踪：销项哪些已收货款、哪些没收（未收金额、是否逾期）；进项是否已付款、未付总额。状态可直接点击设置。
  4. 飞书同步：在「数据备份」点「导出飞书同步包」，发给我即可推送进飞书多维表格，手机上也能看。
数据安全与扩展
  1. 备份：在「数据备份」导出 .json 或 .csv。重要：清浏览器缓存或换电脑前先导出，否则数据会丢。
  2. 下一步：可以让我加「工资社保核算」「利润表」「资产负债表」等模块。
